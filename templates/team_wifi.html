Programming Your Robot Radio

The field broadcasts a network named with your team number (SSID {{.Team.Id}}) secured with the WPA key above. Your robot radio must be programmed with the same team number and key, or it will not connect to the field. Re-program the radio any time the key changes.

Vivid-Hosting VH-109 robot radio (this field uses a VH-113 access point)
{{else}}
OpenMesh OM5P robot radio (this field uses a Linksys/OpenWRT access point)
{{end}} {{if eq .EventSettings.ApType "vh113"}}
  1. Connect your laptop to the radio's DS Ethernet port and power the radio.
  2. Browse to the radio's configuration page: http://{{.RadioAddress}} once it has been set up for your team, or the factory address in the radio's documentation (typically http://192.168.69.1) if it hasn't.
  3. Select Robot Radio mode, enter team number {{.Team.Id}} and the WPA key above, and save. Wait for the radio to reboot.
{{else}}
  1. Connect your laptop to the radio's Ethernet port closest to the power jack and power the radio.
  2. Run the FRC Radio Configuration Utility (installed with the FRC Game Tools).
  3. Enter team number {{.Team.Id}}, choose a bridge (robot) mode for the field's band, enter the WPA key above in the WPA key field, and click Configure.
{{end}}

Exact menu names vary by radio firmware and utility version; if in doubt, ask the FTA.
